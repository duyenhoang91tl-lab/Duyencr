⚙️ Cài đặt Duyên AI - Zalo

Backend chung (dùng chung với Duyên AI - Pancake)

Đây là URL Web App của Google Apps Script backend — cùng 1 backend mà extension Duyên AI - Pancake đang dùng. Nếu đội bạn đã có URL này rồi thì dán lại y hệt vào đây.
Khóa riêng của extension Zalo, admin lấy trong Apps Script (hàm xemKhoaExtension). Không chia sẻ khóa này ra ngoài đội.

⌨️ Viết tắt (gõ tắt trong ô chat)

Gõ viết tắt (hoặc từ khoá) trong ô chat → hiện gợi ý → Tab để chèn, ↑ ↓ đổi lựa chọn, Alt+1…8 chọn nhanh, Esc đóng. Chỉ chèn chữ, không tự gửi. Nội dung có {tên}: gõ thêm tên sau viết tắt (vd ch Huyền) hoặc để tự lấy từ ô "Tên khách" của panel. Thêm / sửa / xoá viết tắt ở CRM → tab Zalo AI → ⌨️ Viết tắt (dùng chung với Pancake AI). Tự cập nhật mỗi 5 phút.

Các cài đặt khác

API key (Groq / Cerebras / Gemini), tên CS đang trực, tự động trả lời AI theo từng khách… được cấu hình trực tiếp trong bảng ⚙ cài đặt nổi trên chính trang chat.zalo.me (không nằm ở trang này), vì các API key này được lưu chung trên backend GAS cho cả team, không lưu riêng theo máy.
